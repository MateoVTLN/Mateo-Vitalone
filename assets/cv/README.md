# CV

Drop your CV PDF in this folder with **exactly** this filename:

```
Mateo_Vitalone_CV.pdf
```

Every "Download CV" button on the site (home page, About page, Academic page)
already points to `assets/cv/Mateo_Vitalone_CV.pdf` — as soon as the file is
committed and pushed, the buttons work. Until then they appear greyed out with
a "CV coming soon" tooltip.
